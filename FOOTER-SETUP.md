# Footer Setup — Resell Lausanne (Wethenew-style)

## Pages to Create in Shopify Admin

Go to **Online Store > Pages** and create each page below.
Use template `page.legal` for legal pages, `page.faq` for FAQ, default `page` for others.

| Handle | Title | Template | Content placeholder |
|--------|-------|----------|-------------------|
| `notre-concept` | Notre concept | page | Qui sommes-nous, notre mission, authenticité |
| `conditions-de-nos-offres` | Conditions de nos offres | page | Détails des promotions et offres en cours |
| `faq` | FAQ | page.faq | Rempli via les blocs FAQ dans le theme editor |
| `vendre` | Vendez votre produit | page | Comment vendre sur notre plateforme |
| `livraison` | Envoi et livraison | page | Zones, délais, tarifs de livraison |
| `echanges-remboursements` | Échanges et remboursements | page | Politique retours 14j, conditions |
| `codes-promos` | Nos codes promos | page | Codes actifs et conditions |
| `mentions-legales` | Mentions légales | page.legal | Raison sociale, SIRET, hébergeur |
| `politique-de-confidentialite` | Politique de confidentialité | page.legal | RGPD, cookies, données personnelles |
| `conditions-generales-utilisation` | Conditions Générales d'Utilisation | page.legal | CGU complètes |
| `conditions-generales-vente` | Conditions Générales de Vente | page.legal | CGV complètes |
| `contact` | Contact | page.contact | Formulaire contact / infos |
| `carte-cadeau` | E-carte cadeau | page | Info carte cadeau |

## Footer Section Settings

In **Theme Editor > Footer**:
- Set `Menu À propos` → `footer-about`
- Set `Menu Services` → `footer-services`
- Set `Menu Collections` → `footer-collections`
- Set `Menu mentions légales` → `footer-legal`
- Set `URL contact` → `/pages/contact`
