# Collection SEO Strategy — high-priority landing pages

Concrete targets for the top money collections. Titles kept ≤~60 chars, meta 120–155. FR is primary (Swiss market); DE/EN via translation rules (`MULTILINGUAL_SEO_PLAN.md`). These map to the theme's existing systems: H1 = `collection.metafields.custom.seo_h1` (or handle override in `collection-plp-header.liquid`); title/meta = `collection.metafields.global.title_tag/description_tag` (else meta-tags handle override); intro = `custom.seo_intro`; FAQ = `custom.collection_faq_items` metaobjects (else theme fallback). **Do not overwrite good merchant-written SEO.**

Filters guidance (per `filters-and-sort`): show **size, brand-model, colorway, price**; hide noisy/auto filters (vendor when redundant with brand, product-type on brand pages). Keep facet URLs `noindex,follow` unless whitelisted.
